# Contributing

Please keep explanations accessible: intuition first, a small numerical example second, formulas third. Preserve chapter IDs `ch1` through `ch21` so shared links continue to work.

- Edit tutorial prose in `index.html`.
- Edit styling in `assets/tutorial.css` and behavior in `assets/tutorial.js`.
- Keep row activations and stored weights `[out,in]` consistent: `Y = X Wᵀ`.
- Clearly label toy calculations and distinguish them from real model configuration values.
- Link factual model claims to official configurations or implementation references.
- Do not replace or modify the supplied diagrams without checking rights and documenting the change.
- Do not commit chat histories, tokens, personal information, model weights or private work material.

Before submitting a pull request, open the site on desktop and mobile. Test chapter contents, attention sliders, causal masking, prefill/reset, recurrent state/reset, diagram zoom/Escape and JSON download. Check for console errors, broken images, broken anchors and page-wide horizontal scrolling.
